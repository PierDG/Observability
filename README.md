# Observability
'001_observability_given_wind_condition' is the main script, by using it it is possible to either plot observability plots or comopute the prediction of the undisturbed wind given the wind condtions at the wind turbines (in terms of wind speed, direction and generated power). To change between prediction and observability it is just needed to change the function called at the beginning at the script (e.g. change 'import Main_function_ti as fun' to 'import Prediction as fun' to change from Observability to Prediction). 3 wind turbines setups are present, it is possible to switch from one to the other by changing their value from 'False' to 'True' at the beginning of the script and then change all the others to 'False'.
